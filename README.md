### Какие сценарии покрыты
- Перевод типов праздников
- Репозиторий: корректный маппинг доменной модели в Room-сущности, маппинг DTO стран.
- ViewModel: обработка отсутствующего праздника при toggle favourite, debounce поиска, `retry()` после ошибок, отмена старого запроса и сохранение актуального результата.
- Room DAO: транзакционная вставка праздника с типами/регионами, каскадное удаление зависимых записей.
- Интеграция `Repository + Room`: сохранение и последующее чтение избранного без потери данных.
- Compose UI: фильтрация списка по поисковому запросу (остается только релевантный элемент), нажатие на иконку избранного с передачей корректного `holidayId`.
